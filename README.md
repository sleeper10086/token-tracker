# 讲解石追踪器

一个自建的 API 用量监控网站：查看各供应商的余额、用量，自动记账，生成月度账单和占比图。

## 功能

- 左侧/右侧各一家供应商卡片，显示**余额**和**本月花费（估算）**
- 每张卡片下方两个小图：**token 用量**、**请求次数**
- 往下滑是**用量对比柱形图**（横轴时间、纵轴花费，不同供应商不同颜色）
- **月度账单**：各家花费、占比饼图
- 右下角「+」号，随时添加新供应商
- 每家供应商一个**中转地址**，把 API 请求指过去即可自动记账

## 快速开始（本地）

```bash
cd jjs-tracker
npm install
npm start
```

然后浏览器打开 http://localhost:3000 ，先注册一个账号。

## 使用步骤

1. **注册登录**（邮箱 + 密码，随便填一个你记得住的即可，只在你自己的服务器上）
2. 点右下角「+」，选择供应商（DeepSeek / Tavily），粘贴你的 **API Key**
3. 卡片上会显示官方**余额/用量**，点「去官网充值」可直接跳转
4. 为了让「本月花费 / 账单 / 对比图」有数据，需要把你的 API 调用**改走中转**：

   - **DeepSeek**（OpenAI 兼容，改 `base_url` 即可）：
     `base_url = https://你的域名/p/端点token`（把 `/v1` 路径保留，例如 `/p/端点token/v1/chat/completions`）
   - **Tavily**：把请求发到 `https://你的域名/p/端点token/search` 等，Key 由中转自动注入

   中转地址在每张卡片底部，点「复制」即可拿到。

## 说明

- API Key 用 AES-256-GCM 加密后存数据库，只在服务端解密，不会下发到浏览器、不会写日志
- 加密密钥首次启动时自动生成，保存在 `data/secret.key`，**备份好它**，丢了就解不开已存的 Key
- 「花费」是按 token × 价格表估算的，价格表在 `src/pricing.js`，可按各供应商最新价格修改
- 支持的供应商在 `src/providers/` 下，每新增一家只需加一个文件 + 在 `index.js` 里登记
